一键启动版 · 先看我
====================

好处：双击 bat 就自动打开编辑器，浏览器【不用再授权 / 选择文件夹】。
原理是一个只监听 127.0.0.1 的本地 Python 小服务代读写文件，
不联网、不上传、不需要账号。


⚠ 但要先把两个文件夹放进鲸鲸的安装根目录
------------------------------------------
    一键启动工具\tools\    →  复制到   鲸鲸根目录\tools\
    一键启动工具\bridge\   →  复制到   鲸鲸根目录\bridge\

「鲸鲸根目录」= 里面有 data\、runtime\、WhaleLauncher.exe 的那一层，
例如 D:\WhaleGirl\。
如果目标文件夹本来就有（tools / bridge 通常已存在），把文件拖进去
【合并】即可 —— 这里只是新增 3 个文件，不要覆盖或替换任何已有文件。

放好后双击：鲸鲸根目录\tools\启动语音编辑器.bat
  · 会弹一个黑色命令行窗口，并自动打开浏览器 http://127.0.0.1:8789/
  · 关掉黑窗口（或 Ctrl+C）就停止服务
  · 端口被占会自动往后找（8789 ~ 8808）
  · 自检：在命令行执行「启动语音编辑器.bat check」，会列出缺哪个文件


Python 从哪来
-------------
bat 优先用鲸鲸自带的 runtime\python\python.exe，
所以【别人不用另外装 Python】；找不到时才用系统 PATH 里的 python。


前提
----
1) 已按《安装说明.txt》装好 voice-tone 插件
2) data\voice-presets.json 已存在（手动放入，或插件首次发语音时自动生成）
3) 已配好 Breeze TTS


注意事项
--------
· 这 3 个文件是【新增】，不修改鲸鲸任何程序文件、不替换 EXE；
  插件本身仍然只用公开的 JavaScript API 4 扩展点。
· 鲸鲸升级时若清理了 bridge\ 里的非官方文件，bat 可能失效，
  把 voice_preset.py 重新复制一次即可（可先跑 bat check 自检）。
· ui 模式不依赖 bridge\voice_reply.py，所以别人的原版鲸鲸（没装过 Python
  补丁）也能正常用；只有命令行的 test 子命令会用到它，不影响编辑器。
· 只想临时改一下、不想往鲸鲸目录放文件的话，用包根目录那个
  voice-preset-editor.html 双击打开也行（需要选一次文件夹）。
· 这个一键启动工具是配套工具，不属于插件包，也不会提交到插件市场 PR。
