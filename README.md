# 鲸鲸语音语气插件 · 配套工具

「语音语气」插件（鲸鲸插件市场 Id：`voice-tone`，作者 @Jy-Levent）的**可视化编辑器与一键启动工具**。
插件本体请从鲸鲸「插件市场」安装；本仓库只放配套工具，让你不用手改 JSON 就能自定义语气。

> ⚠ 插件只适用于 Breeze TTS。

## 文件说明

| 文件 | 用法 |
|---|---|
| `voice-preset-editor.html` | 双击（用 Edge / Chrome）→ 点「选择 WhaleGirl 目录」→ 选鲸鲸安装根目录（含 `data\` 的那层） |
| `语音预设编辑器-使用说明.txt` | 编辑器详细用法与常见问题 |
| `voice-presets.json` | 预设示例（暴躁 / 呆萌）。可放进鲸鲸 `data\`；不放也行——插件首次发语音会自动生成同样内容 |
| `一键启动工具\` | 本地服务版：按里面《先看我.txt》把 `tools\` 和 `bridge\` 复制进鲸鲸根目录，之后双击 bat 自动开浏览器，**无需在浏览器里选文件夹**（优先用鲸鲸自带 Python，无需另装） |
| `安装说明.txt` | 插件的安装与验证步骤 |
| `voice-tone-1.0.1.zip` | 插件本体备份（推荐直接从鲸鲸「插件市场」安装） |

## 能改什么

- 切换 / 新建 / 复制 / 删除预设，一键「✓ 启用这一套」
- 标签规则：音效 tag、触发词 words、正则 pattern，可增删排序
- 语气指令 instructions；「试一句」实时预览
- 保存后：标签规则下一句语音生效；语气指令由插件在下一次发语音时自动同步

## 说明

- 工具不联网、不需要账号，只读写本机 `data\voice-presets.json`；编辑器里不内嵌任何预设数据
- 这些是**独立配套工具**，不属于插件包，也不随鲸鲸插件市场分发
- 基于鲸鲸 / Whale Girl（作者 @Banan1cee，https://github.com/Banan1cee/whale_girl），
  仅使用其公开的 JavaScript API 4 扩展点，未修改任何程序文件

## 不用编辑器，怎么切换语气预设

改一个词就行：

1. 打开 `data/voice-presets.json`（记事本即可）
2. 把最上面的 `"active": "xxx"` 换成要用的预设 key：

   | key | 预设 |
   |---|---|
   | `irritable` | 暴躁（一点就着、带脏字、会吼人） |
   | `adorkable` | 呆萌（慢半拍、语气软） |
   | `normal` | 普通（自然平稳） |
   | `gentle` | 温柔（软和、会接话） |
   | `cold` | 冷酷（惜字如金、叹气多） |

3. 保存，下一条回复就生效，**不用重启鲸鲸**

每套预设里的 `voiceChance`（0-100）是这套自己的语音概率；设为 0 就只在明确要语音时才发。

> 只改 `active` 这一个词，别动别的；JSON 改坏了插件会退回内置默认，从分享包拷一份 `voice-presets.json` 覆盖回去即可。
