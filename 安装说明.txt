鲸鲸 · 语音语气插件 安装说明
================================

作用：让鲸鲸发语音时带上语气音效（叹气、冷笑、哼鼻子、惊呼、抽泣……），
      并且语气指令跟着预设走，不再是一句话一个调子。

前提：
  1) 鲸鲸 4.1.2 或更高版本
  2) 已经在启动器里配好 Breeze TTS 的语音发送（API Key、音色）

⚠ 重要：本插件只适用于 Breeze TTS（api.breeze.blue）。
   音频标签（[叹气] 这类）、instructions 语气指令、sendVoice 的语音文本，
   全部按 Breeze 的协议写。换成别的 TTS 服务商不会生效——
   标签会被当正文念出来，或者语音根本发不出去。


包内文件
--------
voice-tone-1.0.2.zip          插件本体（里面是 plugin.json + plugin.js）
voice-presets.json            预设示例（五套：暴躁 / 呆萌 / 普通 / 温柔 / 冷酷。可不放——插件首次发语音会自动生成同样内容）
voice-preset-editor.html      配套工具：可视化编辑语气（双击打开）
语音预设编辑器-使用说明.txt    配套工具怎么用
一键启动工具\                可选：本地服务版，双击 bat 不用选文件夹（见里面《先看我.txt》）


安装步骤
--------
1) 装插件
   打开鲸鲸启动器 →「插件市场」→ 右上角「从本地安装」→ 选 voice-tone-1.0.2.zip
   装好后在「已安装」里能看到一张叫「语音语气」的卡片。

2) 打开实验总闸
   插件市场页面里有「JavaScript 插件」的实验开关，默认是关的，先打开。

3) 确认权限
   点「语音语气」卡片 → 启用 → 会弹出「完整系统权限」确认，点确认。
   这个插件需要读写 data 下的两个配置文件，所以必须要这个权限。

4) 预设文件（可选）
   不放也行：插件第一次发语音时会自动在 data\ 生成一份默认预设
   （五套：暴躁 / 呆萌 / 普通 / 温柔 / 冷酷，默认暴躁）。想手动放的话，把 voice-presets.json
   复制到鲸鲸的 data\ 目录下（和 config.json 同级的那一层），
   路径示例：D:\WhaleGirl\data\voice-presets.json。
   已存在的预设文件绝不会被插件覆盖。

5) 重启鲸鲸
   重启一次，让内核重新加载插件。


验证
----
随便找个会话发一句：「发个语音给我」
应该收到语音、不收文字。日志里会看到 [voice] stage=decision result=selected


配套工具：可视化编辑语气（推荐）
--------------------------------
不想手改 JSON 的话，双击 voice-preset-editor.html（用 Edge / Chrome），
点「选择 WhaleGirl 目录」选中鲸鲸安装根目录，就能：
  · 切换 / 新建 / 复制 / 删除预设，一键「✓ 启用这一套」
  · 增删改标签规则和触发词、上下调整顺序
  · 改语气指令 instructions、「试一句」实时预览
改完点「保存到文件」：标签规则下一句语音就生效；语气指令由插件在下一次
发语音时自动同步到 voice-send.json，不用手动同步。
详见《语音预设编辑器-使用说明.txt》。

这个编辑器是独立配套工具，不联网、不需要账号，也不属于插件包；
插件升级时它不用跟着换，单独留着即可。

想要双击就打开、不用每次在浏览器里选文件夹：用「一键启动工具\」里的本地
服务版，按里面《先看我.txt》把 tools\ 和 bridge\ 复制进鲸鲸根目录即可。
它会起一个只监听 127.0.0.1 的小服务，优先用鲸鲸自带的 Python，
别人不用另外装；关掉黑色命令行窗口就停止。


常用设置
--------
data\voice-presets.json 里改：
  active           当前用哪套预设（irritable 暴躁 / adorkable 呆萌，也可以自己加）
  presets[x].tags  规则表，从上往下匹配，命中第一个就停
                   每条 { "tag": "[冷笑]", "words": ["气死","烦死"] }
                   tag 只能用官方音效词：叹气 冷笑 哼鼻子 啧嘴 惊呼 吸气 抽泣 轻笑
                   咯咯笑 清嗓 耳语 打哈欠 停顿 结巴 呜咽 闷哼 喊叫 等
                   words 不够用时可以写 "pattern": "正则表达式"

想加一套自己的人设：用编辑器点「＋ 新建预设」或「复制这一套」最省事；
手改也行 —— 复制 presets 里任意一块，改个 key（英文小写），
再把 active 指过去就行。

data\voice-send.json 里改：
  Probability      没被明确要求发语音时，多少概率回语音（默认 25，改成 0 就只在被要求时发）
  Enabled          语音总开关

改完不用重启，下一次合成语音就生效。语气指令（instructions）由插件在下一次
发语音时自动写进 voice-send.json，不用手动同步；在启动器 UI 里手填的语气指令
会被当前预设覆盖，要改请改预设。


切换语气预设（不用编辑器）
------------------------
改一个词就行，不用装任何工具：

1) 打开 data\voice-presets.json（记事本 / VSCode 都行）
   路径示例：D:\WhaleGirl\data\voice-presets.json

2) 找到最上面那行 "active": "xxx"，把 xxx 换成要用的预设 key：

     irritable  →  暴躁（一点就着、说话带脏字、会吼人）
     adorkable  →  呆萌（慢半拍、语气软、会自己笑出来）
     normal     →  普通（自然平稳，只有两三处轻音效）
     gentle     →  温柔（说话软和清楚、会认真接话）
     cold       →  冷酷（惜字如金、叹气和啧嘴多）

3) 保存，下一条回复就生效，不用重启鲸鲸。

顺手可调：每套预设里的 "voiceChance"（0-100）是这套自己的语音概率——
          例如 10 = 大约十句里有一句发语音；设为 0 就只在明确要语音时才发。

注意：
· 只改 active 这一个词，别动别的（JSON 改坏了会读不出来，插件会退回内置默认）
· 保存时保持 UTF-8 编码（记事本默认就是）
· 改坏了：从分享包里再拷一份 voice-presets.json 覆盖回去即可


注意
----
· 这是 community 性质的插件，用的是「完整系统权限」，能读写本机文件。
  只装你自己信任的版本。
· 没配好 Breeze TTS 的话，插件会把语音任务投递出去但发送失败，消息可能收不到。
  建议先在启动器里用「测试语音」确认能正常发声。
· 如果不想用了：插件市场里停用或卸载即可，data\voice-presets.json 可以留着，
  它只被这个插件读取，不影响鲸鲸本身。
