鲸鲸 · 语音预设编辑器 使用说明
================================

这是「语音语气」插件的配套小工具，用来可视化地自定义语气，
不用手改 JSON。它只是一个网页文件，不联网、不上传、不需要账号。


前提
----
  1) 已按《安装说明.txt》装好 voice-tone 插件
  2) data\voice-presets.json 已存在（手动放入，或插件首次发语音时自动生成过一次）
  3) 用 Edge 或 Chrome 打开（需要浏览器的本地文件授权能力）


打开方式（最简单：双击）
------------------------
1) 双击 voice-preset-editor.html
2) 点左上角「选择 WhaleGirl 目录」
3) 选中鲸鲸的【安装根目录】—— 就是里面有 data\ 和 WhaleLauncher.exe 的那一层，
   浏览器会弹一次授权，点「允许」
   ⚠ 选根目录，不要选 data 文件夹本身
4) 编辑器自动读取 data\voice-presets.json，页面上出现预设和规则


另一种方式：一键启动（不用选文件夹）
------------------------------------
分享包里还有「一键启动工具\」：按里面《先看我.txt》把 tools\ 和 bridge\
两个文件夹复制进鲸鲸安装根目录，之后双击 tools\启动语音编辑器.bat，
就会起一个本地小服务并自动打开浏览器，【不用再授权 / 选文件夹】。
  · 只监听 127.0.0.1:8789，关掉黑色命令行窗口即停止
  · 优先用鲸鲸自带的 runtime\python\python.exe，不用另外装 Python
  · 那 3 个文件都是新增，不覆盖任何已有的程序文件
  · 命令行执行「启动语音编辑器.bat check」可自检缺哪个文件
适合经常调语气的人；只是偶尔改一次，用上面的双击 HTML 更省事。


能改什么
--------
· 切换预设：顶部下拉框（带 ★ 的是当前启用的那套）
· 「✓ 启用这一套」：把 active 指过去并保存
· 「＋ 新建预设」/「复制这一套」/「删除这一套」
· 标签规则：每条的音效 tag、触发词 words（也可写 pattern 正则），
  可增删、上下移动；从上往下匹配，命中第一条就停
· 语气指令 instructions：给 TTS 的整体表演指导
· 「试一句」：输入一句话，实时预览会插上哪个音效
· 改完点「保存到文件」


改完什么时候生效
----------------
· 标签规则：插件每次发语音都会重新读 voice-presets.json，
  【下一句语音就生效】，不用重启鲸鲸
· 语气指令 instructions：双击模式下编辑器不直接改 voice-send.json，
  界面上那个「把这段语气同步到 voice-send.json」按钮会提示不能用，
  【这是正常的】—— 插件会在下一次发语音时自动把当前预设的
  instructions 写进 voice-send.json，不用手动同步


常见问题
--------
Q：提示「data 目录里没有 voice-presets.json」
A：先按《安装说明.txt》把预设文件复制到鲸鲸的 data\ 下。

Q：提示浏览器不支持
A：换 Edge 或 Chrome；Firefox / IE 不支持本地文件授权。

Q：启动器里「语气指令」输入框改了没用？
A：正常 —— 插件以当前预设为准，会把那个框覆盖掉。要改就在编辑器里改
  预设的 instructions，或者直接编辑 voice-presets.json。

Q：会上传我的数据吗？
A：不会。它只读写你选中的本地目录，不联网、不记录任何内容；
  编辑器文件里也没有内嵌任何预设数据。


边界说明
--------
· 这是【独立配套工具】，不属于插件包，也不会提交到插件市场 PR：
  市场 PR 只收 plugin.json / plugin.js / 固定版本 ZIP / provenance，
  且插件 ZIP 里只允许放 plugin.json + plugin.js。
· 所以插件升级时这个 HTML 不用跟着换，单独留着即可。
· 配套的「语音语气」插件只适用于 Breeze TTS；换别的 TTS 不生效。
